## Archived — pre-design-system mockups

These nine HTML files were the early UI exploration produced before the TuFolio design system existed (`docs/ui/design-system.md`, `docs/ui/wireframes.md`). They use Merriweather/Manrope fonts (the live spec uses Geist), teal-orange or teal-cyan-rose gradient palettes that don't match the token system, and a tonal direction closer to "flashy SaaS landing" than the serious-but-engaging adult-learning vibe TuFolio is targeting.

**Why this is archived, not deleted:** they're useful as references for *page flow and feature ideas* (e.g. how `tufolio_temario.html` lays out unit progression). They are NOT useful as a styling reference. Do not copy CSS, fonts, gradient values, or component shapes from these files into production code.

**When to consult them:** only when wireframing a new flow that doesn't yet exist in `docs/ui/wireframes.md`, and only for the structural ideas — never the visuals.

The authoritative spec lives in `docs/ui/design-system.md` + `docs/ui/wireframes.md`. The token system lives in `app/globals.css` + `tailwind.config.ts`. The reusable components live in `components/game/`.
